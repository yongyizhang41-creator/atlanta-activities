# Continuous Atlanta night film

`atlanta-night-film.mp4` is one locally hosted 1280×720, 24fps silent H.264 film.
Three Atlanta night shots play in sequence, joined by 0.8-second dissolves,
including the final-to-first loop boundary. No reverse playback. CRF 27,
yuv420p, faststart. `atlanta-night-film.jpg` is its first frame, used only for
loading, playback failure, reduced motion and constrained connections.

Sources downloaded 2026-10-23 from Pexels:
- https://www.pexels.com/video/stunning-night-aerial-view-of-downtown-atlanta-33134647/
- https://www.pexels.com/video/aerial-night-view-of-downtown-atlanta-skyline-33134646/
- https://www.pexels.com/video/night-aerial-view-of-downtown-atlanta-cityscape-33133595/
